## ⚡ Twine Real-Time

[Twine](https://twine-realtime.github.io) is an auto-scaling WebSocket infrastructure designed for modern web applications. It's a drop-in solution that prioritizes connection state recovery, providing a foundation for real-time experiences.

I architected Twine's AWS infrastructure with Elastic Beanstalk and Docker so any company could deploy their own instance into their own AWS account with a single CLI command, and led the fix for Socket.IO scaling issues that reduced connection failure rates from 20–40% to 2–4% under load.

*Technologies Used: TypeScript, Socket.IO, Docker, and AWS (DynamoDB, ElastiCache for Redis, EC2, ALB, ELB, CloudFront, S3).*

## 🚚 LoadUp

At LoadUp, I independently designed and built Elasticsearch search infrastructure from scratch, reindexing tens of millions of records and cutting query times by 70%+, along with the API powering LoadUp's booking tool end to end and the integration connecting Kustomer AI to automate quote creation, on a Rails platform supporting $35M in annual revenue across 152,000+ transactions.

*Technologies Used: Ruby on Rails, Elasticsearch, Sidekiq, GraphQL, PostgreSQL, Redis, Stripe, Datadog.*
